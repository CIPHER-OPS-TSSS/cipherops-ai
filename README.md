# 🛡️ CipherOps AI — Intelligent Criminal Records & Investigation Management System

CipherOps AI is an enterprise-grade full-stack investigation intelligence platform designed for authorized law enforcement personnel, prosecutors, supervisors, and forensic analysts. It combines real-world geospatial mapping, interactive entity graph analytics, tamper-evident cryptographic chain of custody logging, OCR document ingestion, and grounded AI decision support.

---

## 🏛️ System Architecture

- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS (Dark Graphite `#0b0f17` palette with cyan `#06b6d4` highlights), React Leaflet, Recharts, Lucide Icons.
- **Backend**: Node.js, Express.js, TypeScript, REST API architecture, JWT authentication, RBAC authorization, tamper-evident SHA-256 ledger chaining.
- **Database**: PostgreSQL with Prisma ORM, pgvector schema, full-text search indexing, and resilient local persistence store.
- **AI Engine**: Retrieval-Augmented Generation (RAG) assistant delivering structured 7-section answers with source citations, hybrid semantic document search, and unverified relationship discovery.
- **Security & Provenance**: Append-only custody logs, rolling cryptographic hashes, role-based endpoint protection, and audit trails.

## 🚀 Quick Start Guide

### 1. Prerequisites
- Node.js (v18+ or v20+)
- npm (v9+)
- (Optional) Docker & Docker Compose for containerized PostgreSQL

### 2. Install Dependencies
```bash
# In the root repository directory:
npm install
```

### 3. Build the Application
```bash
# Compile both backend and frontend:
npm run build
```

### 4. Run Automated Tests
```bash
# Run backend and frontend Vitest suites:
npm run test
```

### 5. Launch Development Servers
```bash
# Start backend on :4000 and frontend on :5173 concurrently:
npm run dev
```
Open **[http://localhost:5173](http://localhost:5173)** in your browser.

## ⚖️ Ethical Safeguards & Decision-Support Mandate

1. **Decision Support Only**: The AI never determines guilt, predicts criminality from personal traits, or recommends automated punitive enforcement.
2. **Grounded Citations**: Every claim generated by the AI Case Assistant cites specific document numbers and excerpts.
3. **Unverified Link Safeguard**: AI-suggested connections remain visibly tagged as unreviewed until approved by an authorized supervisor.
4. **No Automated Merging**: Suspect duplicate records are surfaced for human review and are never automatically merged.
